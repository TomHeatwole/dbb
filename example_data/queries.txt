API doc for how I got the example data in this directory.

All from sleeper API's documentation: https://docs.sleeper.com/

Matchups: "https://api.sleeper.app/v1/league/<league_id>/matchups/<week>"
Users: "https://api.sleeper.app/v1/league/<league_id>/users"
Rosters: "https://api.sleeper.app/v1/league/<league_id>/rostres"
League: "https://api.sleeper.app/v1/league/<league_id>"
Traded Picks: "https://api.sleeper.app/v1/league/1194868087212167168/traded_picks"
ESPN Scores: "https://site.api.espn.com/apis/site/v2/sports/football/nfl/scoreboard"
ESPN Scores by day (preseason): "https://site.api.espn.com/apis/site/v2/sports/football/nfl/scoreboard?dates=20250816&seasontype=1"
ESPN Scores by week: "https://site.api.espn.com/apis/site/v2/sports/football/nfl/scoreboard?week=5&year=2025&seasontype=2"
Trending Add (Sleeper): "https://api.sleeper.app/v1/players/nfl/trending/add?lookback_hours=24&limit=100"
