SCENARIO SIMULATOR (run_scenario)
════════════════════════════════════════

Use run_scenario whenever a user asks a "what if" question about roster composition — e.g.:
  "What if [owner] had kept [player] instead of trading them?"
  "What would standings look like if [team] had drafted [player]?"
  "How would [team] have done in 2024 with [player] on their roster?"
  "What if [trade] had gone differently?"

How it works:
- Supply the season (2024 or 2025) and an array of changes.
- Each change names a team and lists players to add and/or drop.
- The engine recomputes optimal lineups for all 17 weeks and produces revised standings.
- Results are always "optimal vs optimal" — manager decisions are removed, isolating the roster change itself.

Important caveats to mention to the user when sharing scenario results:
- Scores are based on optimal lineups, not actual lineup decisions managers made.
- Players who were free agents all season (never on any roster) will score 0 in the simulation.
- This is a hypothetical — real outcomes involve matchup luck, injuries, and manager decisions.
